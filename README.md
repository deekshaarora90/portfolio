# Deeksha Arora - Minimal Portfolio

A minimalist, dark-themed personal portfolio website built with pure HTML and CSS.

## Overview
This project is a personal website designed to showcase my profile, technical skills, and interests in a clean, aesthetic manner. It adheres to a strict "no emoji" policy and focuses on high contrast and typography.

## Features
- **Minimalist Design:** Clean aesthetic with a dark theme (`#0a0a0a`).
- **Responsive:** Looks good on mobile and desktop.
- **Zero Dependencies:** Built with vanilla HTML5 and CSS3. No frameworks or libraries.
- **Fast Loading:** extremely lightweight.

## Structure
- `index.html`: Main HTML structure.
- `style.css`: Stylesheet containing all design rules and variables.

## How to Run
Simply open the `index.html` file in any modern web browser.

```bash
# On macOS
open index.html
```

## Customization
- **Fonts:** Uses 'Inter' from Google Fonts.
- **Colors:** Defined as CSS variables in `style.css` for easy theming.
